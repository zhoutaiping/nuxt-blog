# 潮流周刊博客

基于 Nuxt 3 的周刊博客，支持黑白主题切换。

## 部署信息

- **静态托管地址**: https://cloudbase-0g3dkj1pc3bdcf50-1257729872.tcloudbaseapp.com/
- **环境 ID**: cloudbase-0g3dkj1pc3bdcf50
- **部署时间**: 2026-05-09 13:45

## 技术栈

- Nuxt 3 + Vue 3
- @nuxt/content (内容管理)
- Tailwind CSS
- @nuxtjs/color-mode (主题切换)

## 本地开发

```bash
npm install
npm run dev
```

## 部署

```bash
npm run generate
# 将 .output/public 目录上传到 CloudBase 静态托管
```
