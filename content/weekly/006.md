# TypeScript 6.0 正式发布

TypeScript 6.0 于 2026 年 3 月 23 日正式发布。这个版本不是一个"炫技型"大版本，而是为 TypeScript 7.0（原生速度）铺路的过渡版本。

## 核心变化

### 默认值变更

TypeScript 6.0 变更了一些默认配置，使其更符合现代开发实践：

- **target 默认值**：现在默认为 `ES2025`
- **module 默认值**：现在默认为 `ESNext`
- **strict 默认值**：保持 `true`，强化类型安全

### 新增特性

- **Temporal 类型支持**：原生支持 Temporal API 类型定义
- **ES2025 支持**：支持最新 ECMAScript 特性
- **装饰器元数据**：增强装饰器功能

```typescript
// Temporal API 类型支持
const now = Temporal.Now.instant();
const zonedDateTime = now.toZonedDateTimeISO('Asia/Shanghai');

// 装饰器元数据
function Log() {
  return (target: any, propertyKey: string, descriptor: PropertyDescriptor) => {
    // 元数据支持
    const metadata = Reflect.getMetadata('design:paramtypes', target, propertyKey);
    console.log(`Method ${propertyKey} params:`, metadata);
  };
}
```

### 弃用与迁移提示

TypeScript 6.0 开始弃用一些旧选项，并给出迁移提示：

- `charset` 选项已弃用，推荐使用 UTF-8 编码
- `preserveConstEnums` 默认值变更
- 为 TypeScript 7.0 的原生速度做准备

## 升级建议

1. **更新 TypeScript**：`npm install typescript@6.0`
2. **检查配置**：运行 `tsc --init` 查看新默认值
3. **修复弃用警告**：根据编译器提示更新代码
4. **测试兼容性**：确保项目在 TS 6.0 下正常运行
