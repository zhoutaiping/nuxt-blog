# Next.js 16 全栈开发

Next.js 16 于 2025 年 10 月正式发布，这个版本带来了许多新功能和改进，标志着全栈 React 应用开发进入一个新时代。

## 核心新特性

### 服务器操作（Server Actions）增强

Next.js 16 进一步增强了服务器操作功能，使其更加稳定和易用：

```typescript
// app/actions.ts
'use server'

export async function createPost(formData: FormData) {
  const title = formData.get('title')
  const content = formData.get('content')
  
  // 直接在服务器上操作数据库
  await db.post.create({
    data: { title, content }
  })
  
  revalidatePath('/posts')
}
```

### 缓存策略优化

Next.js 16 引入了更细粒度的缓存控制：

- **fetch 缓存**：默认 `force-cache`，可配置
- **路由缓存**：客户端路由缓存优化
- **增量静态再生成（ISR）**：支持按需重新验证

### Turbopack 成熟

Turbopack 作为 Webpack 的 Rust 替代品，在 Next.js 16 中更加成熟：

- 冷启动速度提升 700%
- 热模块替换（HMR）速度提升 400%
- 生产构建稳定性大幅提升

## 升级指南

从 Next.js 15 升级到 16：

```bash
# 使用 codemod 自动迁移
npx @next/codemod@latest upgrade latest

# 或手动更新
npm install next@16 react@19 react-dom@19
```
