# CSS 新特性

2026 年，CSS 迎来了一系列激动人心的新特性。这些新特性让前端开发变得更加简单和高效。

## CSS Anchor Positioning

CSS Anchor Positioning（锚点定位）终于实现了全浏览器支持！这个特性简化了 popover、tooltip、下拉菜单等组件的定位开发。

```css
/* 定义锚点 */
.button {
  anchor-name: --button-anchor;
}

/* 使用锚点定位 */
.tooltip {
  position: fixed;
  position-anchor: --button-anchor;
  top: anchor(bottom);
  left: anchor(center);
  translate: -50% 0;
}
```

不再需要 JavaScript 计算位置了！

## CSS Scroll-driven Animations

滚动驱动动画让你可以创建基于滚动位置的动画，无需 JavaScript：

```css
@keyframes fade-in {
  from { opacity: 0; }
  to { opacity: 1; }
}

.header {
  animation: fade-in linear;
  animation-timeline: scroll();
}
```

## 其他新特性

### :has() 选择器

`:has()` 选择器被称为"父选择器"，终于得到广泛支持：

```css
/* 选择包含 img 的 a 标签 */
a:has(img) {
  display: block;
}

/* 选择后面跟着 h2 的 p 标签 */
p:has(+ h2) {
  margin-bottom: 2rem;
}
```

### 容器查询（Container Queries）

容器查询允许你根据容器大小而非视口大小应用样式：

```css
.card {
  container-type: inline-size;
}

@container (min-width: 400px) {
  .card {
    display: grid;
    grid-template-columns: 1fr 2fr;
  }
}
```
