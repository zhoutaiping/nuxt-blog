# Rust 工具链在前端的应用

Rust 工具链正在前端领域规模化落地。SWC、Turbopack、Biome 等工具正在取代传统的 JavaScript 工具链，带来显著的性能提升。

## SWC：速度之王

SWC 是基于 Rust 的 JavaScript/TypeScript 编译器，速度比 Babel 快 20-70 倍：

```javascript
// .swcrc 配置
{
  "jsc": {
    "parser": {
      "syntax": "typescript",
      "tsx": true
    },
    "target": "es2020"
  }
}
```

Next.js、Parcel、Deno 等工具都已经采用 SWC 作为默认编译器。

## Turbopack：Webpack 的继任者

Turbopack 是由 Webpack 创始人开发的基于 Rust 的打包工具：

- **增量计算**：只重新构建变更的部分
- **并行处理**：充分利用多核 CPU
- **内存效率**：比 Webpack 少用 90% 的内存

```bash
# 使用 Turbopack 启动 Next.js
next dev --turbo
```

## Biome：一站式工具链

Biome 是一个基于 Rust 的前端工具链，集成了格式化、 linting、重构等功能：

```bash
# 格式化代码
biome format --write ./src

# Lint 代码
biome lint ./src

# 一站式修复
biome check --apply ./src
```

Biome 的目标是取代 ESLint + Prettier + Babel 的组合。

## 其他 Rust 前端工具

### Rome（已停止维护，推荐使用 Biome）

Rome 是 Biome 的前身，虽然已停止维护，但它的理念影响了整个前端工具链。

### Lightning CSS

Lightning CSS 是一个基于 Rust 的 CSS 编译器，支持：

- 自动添加浏览器前缀
- CSS 压缩
- 现代 CSS 特性转换

```javascript
// vite.config.js
import { defineConfig } from 'vite'

export default defineConfig({
  css: {
    transformer: 'lightningcss'
  }
})
```
